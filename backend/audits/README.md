# Data reliability audits

Store dated audit summaries and supporting aggregate observations here.

and unknowns. Never store credentials, private connection strings or raw civic
descriptions here. Phase 1.1 observations are in `2026-11-01-phase1_1/`.

The [bounded geocoding pilot](2026-11-01-geocoding-pilot/REPORT.md) records
25 live Census requests and independent SanGIS diagnostics. Its cached
validation can be reproduced without further provider calls.
