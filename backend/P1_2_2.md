Google is **not a production provider**. No Google key is configured, no paid
live request was authorized or made, and no historical geocoding was run.

## Implementation and production boundary

| File | Purpose |
| --- | --- |
| `agent/google_geocoding.py` | Opt-in v3 adapter, strict response validation, precision, request/rate/quota controls |
| `agent/geocoding_review.py` | Isolated selective-review prototype; default `enabled=False`, not wired into Agent |
| `agent/geocoding_http.py` | Optional no-redirect transport mode for exact Google attempt accounting; existing defaults preserved |
| `verification/geocoding_benchmark/google_evaluation.py` | Reuses saved free-provider results, selects 12 cases, explicit live gate, no Google-content persistence |
| `scripts/audit_historical_locations.py` | Read-only status audit and deterministic stratified sampling; cached exact-name open-road evidence |
| `agent_tests/test_google_geocoding.py` | Mocked provider, budget, policy, workflow, output-retention and audit tests |
| `.env.example` | Empty optional `GOOGLE_MAPS_API_KEY` placeholder; real `.env` unchanged |
| `README.md`, `AGENT.md`, this document and linked reports | Scope, operation, limits and next decisions |

No dependency was added. Existing repository-root dotenv loading is reused.
The experimental review switch is a constructor option, not a deployed runtime
environment flag. The production Agent still uses the P1.2.1 Census-primary
adapter with SanGIS only on legitimate Census no-match.

Google HTTP needs **both** an explicitly authorized live adapter and a configured
key. The benchmark additionally requires `--live-google`, caps the frozen
experiment at 15 actual attempts and leaves an exclusive repeat-run marker.
Do not configure a key in frontend JavaScript or pass one on the command line.

The prototype policy queries both free providers only when explicitly enabled.
It treats >100 m as a review trigger, not a correctness test. Conflicting valid
locations remain candidates; Google proximity never chooses a winner. A unique
fully validated Google ROOFTOP candidate after no usable free candidates may be
resolved in that experimental policy; partial/interpolated/approximate/multiple
results require review. This is a tested proposal, **not evidence of live Google
quality**, and cannot be deployed until Phase A's usefulness gate is satisfied.

## Commands

Run without Google or other geocoder requests:

```powershell
.\.venv\Scripts\python.exe -m backend.verification.geocoding_benchmark.google_evaluation
.\.venv\Scripts\python.exe -m pytest backend/agent_tests/test_google_geocoding.py backend/agent_tests/test_sangis_geocoding.py backend/agent_tests/test_location_flow.py -q
```

The historical audit reads the existing database and frozen road cache:

```powershell
.\.venv\Scripts\python.exe -m backend.scripts.audit_historical_locations --sample-size 160
```

The initial bounded road lookup was eight REST requests, not a collision
geocoding batch. Reproduction does not re-fetch cached geometry.
